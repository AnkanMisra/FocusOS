# Opik Integration

Opik is used as the primary evaluation and observability layer.

## What is Tracked
- Agent traces per run
- Prompt versions
- Strategy identifiers
- Evaluation scores
- Behavioral outcomes

## Experiments
Each strategy variant is logged as an Opik experiment.
Dashboards are used to compare performance across runs.

## Purpose
- Detect regressions
- Identify failure modes
- Demonstrate measurable agent improvement
