# Experiment Design

FocusOS runs controlled experiments on agent behavior.

## Variable Dimensions
- Coaching tone: strict vs empathetic
- Focus block length: 25 vs 40 minutes
- Plan density: light vs aggressive

## Fixed Inputs
- Same user goal
- Same availability
- Same day constraints

## Comparison Criteria
- Completion rate
- LLM evaluation scores
- Drop-off points

Poorly performing strategies are deprecated over time.
